SQL vs NoSQL

The practical interview distinction: data model, schema, relationships, transactions and scaling — not simply centralized vs distributed.

Important: Both SQL and NoSQL databases can be deployed in centralized or distributed environments.

SQL

  • Relational tables, rows and columns.
  • Predefined schema and strong relationships.
  • SQL queries, joins and constraints.
  • Strong transactional guarantees are common.

NoSQL

  • Key-value, document, wide-column or graph models.
  • Often flexible schema and denormalized data.
  • Query model varies by database.
  • Often designed for high scale, availability or specialized access patterns.

02

How modern SQL can be distributed

Relational does not mean single-node.

Sharding / partitioning

Split rows across nodes using a partitioning key.

Application
↓

Node 3Users 2001–3000

Replication

Keep copies of data on multiple nodes for availability and read scaling.

  • Partitioning decides where data lives.
  • Replication decides how many copies exist.
  • Distributed transactions coordinate changes that span nodes.
Examples: Google Spanner, CockroachDB, YugabyteDB and TiDB provide distributed relational capabilities while retaining SQL interfaces.
03

When to choose SQL

Use the relational model when relationships and transactions dominate.

  • Data is structured and relational.
  • Complex queries and joins are required.
  • ACID transactions and consistency are critical.
  • Examples: banking, ERP, inventory, financial workflows and reporting.
04

When to choose NoSQL

Use a specialized model when scale, access pattern or schema flexibility is the priority.

  • Data is unstructured or semi-structured.
  • Very high scale, throughput or availability is important.
  • Schema changes frequently or differs between records.
  • Access patterns fit a key-value, document, wide-column or graph model.
Interview shortcut: Don't say “SQL = vertical, NoSQL = horizontal.” A better answer is: SQL vs NoSQL is primarily a data-model and database-paradigm choice. Modern systems can distribute either model using partitioning and replication.
