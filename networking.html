Networking Building Blocks

Proxy, reverse proxy, load balancer, firewall and VPN — what sits where and why it exists.

Proxy

A proxy acts on behalf of the client when communicating with another service.

  • Client → Proxy → Internet/server.
  • Can hide client identity, apply policy, cache responses or control outbound access.

Reverse Proxy

A reverse proxy sits in front of backend servers and receives requests on their behalf.

  • Client → Reverse Proxy → Backend.
  • Can provide TLS termination, routing, caching, compression and access control.

Load Balancer

Distributes traffic across multiple backend instances.

  • Improves availability and horizontal scalability.
  • Common strategies include round robin, least connections and weighted routing.
  • Health checks remove unhealthy instances from rotation.

Firewall

Controls network traffic according to security rules.

  • Can allow or deny traffic based on IP, port, protocol and other attributes.
  • Network firewalls and application-layer firewalls solve different problems.

VPN

Creates an encrypted tunnel between networks or endpoints over an untrusted network.

  • Common for private access to corporate/cloud networks.
  • Provides secure transport, but does not automatically make every application secure.

Proxy vs Reverse Proxy

The easiest interview distinction.

Quick comparison
ComponentSits on behalf ofTypical directionCommon jobs
Forward ProxyClientClient → InternetOutbound policy, anonymity, caching
Reverse ProxyServer/backendInternet → BackendRouting, TLS termination, caching, protection
Load BalancerBackend poolClient → one of many serversDistribution, health checks, failover
FirewallNetwork boundaryTraffic in/outAllow/deny security policy
VPNPrivate network connectionEndpoint/network ↔ endpoint/networkEncrypted private connectivity
Interview shortcut: A proxy represents the client; a reverse proxy represents the servers. A load balancer is focused on distributing traffic, a firewall on controlling traffic, and a VPN on creating secure private connectivity over an untrusted network.
